Changelog
v3.0 — Kecepatan, harga live, no-sleep saat ini
• Analisis PARALEL dalam batch — 5 saham jalan bersamaan, bukan satu per satu
• Jeda dikurangi: 1500ms → 200ms antar batch, Yahoo timeout 12s → 6s
• Holdings menampilkan harga Yahoo live + % perubahan + badge usia data
• Tombol "↻ Refresh harga" — update harga holdings tanpa analisis ulang
• Wake Lock API — analisis tidak berhenti meski layar dimata/minimize di Safari
• Estimasi waktu: sebelumnya ~45 detik → sekarang ~15-20 detik
v2.9 — Data live Yahoo Finance + multi-proxy
• Multi-proxy fallback: allorigins → corsproxy.io → thingproxy (auto-coba sampai berhasil)
• Validasi freshness data: reject jika lebih dari 48 jam (stale data tidak dikirim ke AI)
• Badge data age di kartu saham: LIVE / Xj lalu / EOD / EST
• Yahoo data disimpan di state untuk badge persistent
• Data delay: 15 mnt saat pasar buka, EOD setelah tutup — memenuhi syarat "min 1 hari"
v2.8 — Fix confidence selalu low
• Prompt diperkaya: anchor harga referensi per saham + definisi HIGH/MEDIUM/LOW yang eksplisit
• JSON template pakai harga nyata (bukan 0) + TP/SL otomatis ±5%/±12%
• maxTokens ditingkatkan 280 → 400 supaya JSON tidak terpotong
• JSON parser lebih robust: support nested object + auto-fix trailing comma
• validateRec: harga 0 diganti fallback harga referensi per saham
v2.7 — Smart scoring kandidat (A+B)
• Fase 1 filter 15 kandidat dibagi 3 batch prioritas (5+5+5)
• Batch 2 dan 3 hanya dijalankan jika batch sebelumnya belum dapat 5 rekomendasi
• Stop otomatis saat sudah dapat 5 rekomendasi medium/high confidence
v2.5 — Retry saat confidence low
• Jika confidence LOW, AI coba ulang max 2x dengan angle berbeda
• Attempt 1: analisis umum · Attempt 2: fokus teknikal · Attempt 3: fokus fundamental
• Temperature dinaikkan di retry supaya AI tidak copy jawaban sebelumnya
• Hapus groq/compound sepenuhnya — selalu "entity too large" karena return raw HTML search
• Semua analisis sekarang pakai llama-3.3-70b-versatile saja (cepat, terkontrol)
• 1 call per saham, output max 280 token — tidak ada lagi entity too large
• Harga bersifat estimasi AI — disclaimer ditambahkan di UI
v2.2 — Fix model name sebelumnya
• Fix nama model: compound-beta → groq/compound
• Tambah fallback chain: groq/compound → groq/compound-mini → llama-3.3-70b
• Retry otomatis baca waktu tunggu dari pesan error rate limit
• Timeout 60 detik untuk compound model
v2.1 — 2-fase filtering
• Sistem 2 fase: filter kandidat dulu (llama), baru analisis dalam (compound)
• Hemat 70% token usage dibanding versi sebelumnya
• Analisis per saham satu per satu (bukan sekaligus)
• Countdown timer di loading screen
v2.0 — Groq Compound web search
• Beralih dari Yahoo Finance + proxy ke Groq Compound built-in web search
• Tidak perlu API data terpisah
• Live search log tampil saat analisis berjalan
• Support multi-provider: Gemini, Groq, Claude
